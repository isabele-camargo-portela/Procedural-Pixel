# 🗺️ Procedural-Pixel
> **Status:** 🟡 Em desenvolvimento

Projeto de geração procedural de mundos 2D em pixel art para estudo de Programação Orientada a Objetos (POO) em Java.

## 📌 Sobre o projeto

Este é um projeto pessoal de estudos pensado para praticar algoritmos, lógica de programação e Programação Orientada a Objetos por meio da geração procedural de mundos.

A proposta é criar um mundo 2D com visão top-down, utilizando sprites em pixel art e algoritmos de geração de terrenos. A geração do mundo será feita gradualmente, conforme a câmera se movimenta, utilizando regiões ou chunks.

O mundo terá limites definidos, e novas funcionalidades poderão ser adicionadas conforme o desenvolvimento avançar.

### 🚀 Objetivos
* Praticar lógica de programação e resolução de problemas.
* Estudar e aplicar conceitos de Programação Orientada a Objetos.
* Explorar algoritmos de geração procedural de mundos.
* Desenvolver habilidades em Java.

### 💻 Tecnologias

* Java 🍵
